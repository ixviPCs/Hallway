This #Hallway

**A lightweight, school-friendly chat platform inspired by Discord.**

Hallway is an experimental chat application designed to provide a Discord-like communication experience in environments where Discord may be unavailable or blocked. It aims to give students a place to communicate, hang out, and build communities within their schools.

Hallway is currently a work in progress. Expect bugs, unfinished features, and unexpected behavior.

This project is experimental, and stability is not guaranteed. If you encounter a bug, please report it through the repository's [Issues](../../issues) tab, including steps to reproduce the problem whenever possible.
